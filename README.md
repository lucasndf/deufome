🍽️ Deu Fome – Página de Links e Cardápio

Este é o Linktree oficial do DEU FOME, criado para centralizar informações do restaurante, cardápio, localização e contato para pedidos via WhatsApp.
O objetivo é oferecer uma página simples, rápida e totalmente responsiva para facilitar o acesso dos clientes.

✨ Funcionalidades

Exibição do cardápio com preços atuais
Link direto para WhatsApp com botão destacado
Informações completas: endereço, horário e delivery
Mapa integrado via Google Maps
Layout simples, leve e intuitivo
Estilo personalizado com fonte Fredoka

🛠️ Tecnologias Utilizadas

HTML5
CSS3 (arquivo style.css)
Font Awesome (ícones)
Google Fonts – Fredoka
Google Maps Embed
